    See it in action

    Everything in these clips runs from one file on the device. They were recorded with the internet connection cut; only the captions and the dots that mark each tap were added afterwards.

    Photograph a sign, find the place

    Take a picture of a street sign, a shop front or the address on a hotel key card, and the map looks for the place it names. The text is read on your device, in the script it is written in: here Ukrainian, Greek, Arabic, Japanese, Korean, Chinese and English, side by side.

    Download the map in it

    On your language's page, each map's main button downloads the map in that language, as one .zim file. This English page gives each map as it was built: place names in the local language, the interface and Wikipedia in English.

    Another language?

    Many maps can also be made in languages spoken there, such as Catalan for Iberia or Welsh for Britain and Ireland. Maps in other languages lists every language of every map and assembles the file in your browser.

    What is it?

    StreetZim packages OpenStreetMap data — entire countries or continents — into a single ZIM file you can open in Kiwix. It works completely offline: no servers, no API calls, no internet required after the initial download.

    Unlike traditional offline map apps that ship raster tiles, StreetZim uses vector tiles rendered client-side with MapLibre GL JS. The result: smooth pan, zoom, rotation, and even 3D terrain — all from a single file on your device.

    Vector Maps

    Smooth, sharp street-level maps with the OpenMapTiles schema, rendered live by MapLibre.

    Satellite Imagery

    10-meter resolution Sentinel-2 cloudless imagery for the entire mapped region.

    3D Terrain

    Hillshade and 3D elevation from the Copernicus GLO-30 global DEM.

    Wikipedia & Wikidata

    Tap any city, mountain, or landmark for its Wikipedia article and key facts.

    Full-Text Search

    Search across millions of place names, streets, parks, peaks, airports, and POIs.

    Truly Offline

    Just one .zim file. No accounts, no telemetry, no network. Open and go.

    How to Use

    1

    Install Kiwix

    Free reader for iOS, Android, Mac, Windows, and Linux. Get it at kiwix.org. On Windows and Linux, open maps in the Kiwix PWA for now: Kiwix Desktop 2.5 shows them blank, and its fix is only in the nightly builds so far.

    2

    Download a map

    Pick a region above and download the .zim file (or grab the torrent for faster speeds).

    3

    Open in Kiwix

    Open the .zim file in the Kiwix app. That’s it — the map runs entirely offline.
