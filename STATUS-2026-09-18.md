## Bugs found and fixed today

- `e78a67b` — `main()` had a local `import shutil` shadowing the module import,
  so the `finally: shutil.rmtree(tmpdir)` raised `UnboundLocalError` **after a
  fully successful build**, and `build-refresh-queue.sh:282` reads rc≠0 as BUILD
  FAILED and discards the region. Only bites when `--keep-temp` is absent.
- `3910bfc` — `--max-zoom` was **silently ignored for any region whose mbtiles is
  ≤ 5 GB**: `use_streaming = mbtiles_size_gb > 5.0`, and only the streaming path
  filtered. Small regions took `extract_tiles_from_mbtiles()`, whose SQL had no
  zoom predicate. Verified no-op for existing builds (all 50 region mbtiles top
  out at z14).
- `b37e12d` — the web smoke **cannot** detect a stale in-ZIM viewer: `sw.js`
  `VIEWER_SHELL_NAMES` serves viewer files from the site. Added
  `cloud/kiwix_viewer_gate.sh` (real kiwix-serve 3.8.2 in `tools/`) +
  `cloud/zim_viewer_smoke.mjs`. Control run with `EXPECT_FIXES=0` proves it can
  fail. **kiwix-serve needs `setsid` and ~30 s to map a 2 GB ZIM; results in
  places.html are bare `<li>` under `<ol id="results">`.**
- `b861cc4` — merged `claude/kind-fermat-tfq52d` (mobile fixes). It auto-merged
  with 0 conflicts but their branch carried **neither** `loadWikiGeoIndex` nor
  `retryWikiGeoIndex`, and rewrote the same region. Verified after merging that
  `wiki-geo-index.json` is fetched exactly once by the retrying loader.

## Gotchas that cost time today

- Don't trust `free`/RSS extrapolation — read `/proc/pressure/memory`.
- Don't count your own grep or a `bash -c` wrapper as the process.
- The harness kills `run_in_background` jobs on "low memory"; use `setsid nohup`.
- `viewer-refresh-queue.sh` pins `SRC` to the **live archive.org filename**
  (`tmp/live-inventory.out`), never "newest local dated ZIM" — several regions
  have newer local artifacts that were built but never shipped.
- `web/generate.py:578` `_DATED_ZIM_RE` accepts the `[a-z]` suffix, so `…18b.zim`
  is visible to the catalog. `cleanup_old_zims.py --keep 2` prunes the old one.
